# ID Tunner — instaladores Windows

Este repositório distribui os instaladores e os metadados de atualização do ID Tunner.

Baixe a versão estável em [Releases](https://github.com/henriquedtr/idtunner-releases/releases/latest).

A partir da versão 0.12.0, use **Ajuda → Atualizações pela internet** no aplicativo. A consulta e o download são iniciados pelo usuário; a instalação pede confirmação para reiniciar. Salve relatórios antes de atualizar, pois sessões e arquivos em memória não persistem após o reinício.

O aplicativo mantém arquivos originais e a pasta de coleta. A distribuição atual não possui assinatura Authenticode. O atualizador verifica a integridade SHA-512 do instalador contra os metadados publicados.

As funções reais de comunicação HEX-V2 e gravação de ECU continuam em desenvolvimento. Atualizar o aplicativo não libera operações indisponíveis.
